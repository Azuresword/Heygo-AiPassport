English · 简体中文

Heygo · AI Passport · Technical report

Ski data and voice coach terminal

AI Passport connects an ESP32-C3 device to a phone through BLE. It provides live ski data, run reports, turn browsing, and voice coaching. The device handles keys, display, recording, and playback. The phone handles data analysis, speech processing, and access to the AI service.

Report baseline: 2026-10-18, version 284ab00, Sprints 0–17. The metrics below describe this stage.

Functional scope

Increment 1

Coach voice

On the Coach page, the user holds OK to record and releases it to send. The phone transcribes speech, requests an AI answer, and generates speech. The device plays the answer. Recording lasts at most 20 seconds.

Increment 2

Run data and report

The device displays speed, drop, distance, turn count, and time. Each run has a Heygo IQ score (0–200) and one tip. When the phone detects a run start, it requests the live data page.

Increment 3

Turn browsing

Each page displays 8 turns with speed, angle, and radius. The device caches 3 groups and requests other groups from the phone as needed.

Increment 4

Phone popups

Popups include fall alerts, voice notices, issue reports, and achievement reports. A 10-second countdown starts after playback, or immediately without audio. Any key closes the popup.
