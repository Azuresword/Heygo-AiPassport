# HeygoAI 与 AI Passport：产品需求

版本：0.9。日期：2026-10-17。状态：评审草案。
产品负责人尚未指定。
本文定义项目概念，不代表联动功能已经实现。

## 1. 产品目标

滑雪者滑行时在设备上看实时数据，休息时向 AI 教练提问并听到回答。
滑雪者不用拿出手机，也不用摘手套。

HeygoAI 通过待确认的接口提供滑雪分析和教练能力。
手机应用负责语音识别、语音合成、滑行数据和与 HeygoAI 的连接。
AI Passport 提供按键、麦克风、喇叭和一块小屏幕。

使用时手机留在口袋里。设备通过手机连网。
所以设备省掉的是"把手机拿出来"，不是手机本身。

## 2. 用户与使用时机

| 用户 | 需求 | 使用时机 |
| --- | --- | --- |
| 休闲滑雪者 | 不看手机，也知道这一趟滑了多少。 | 滑行中。 |
| 休闲滑雪者 | 不看手机长报告，也知道这一趟的问题和下一趟怎么改。 | 一趟滑完后，坐缆车或休息时。 |
| 正在练习技能的滑雪者 | 下一趟之前得到一条简短建议。 | 下一趟开始前。 |
| 项目测试者 | 复现一次失败的提问或一次错误的数据显示。 | 室内测试时。 |

试用阶段面向成年人和小范围群组。
试用使用现有开发板，不需要新电路板或新外壳。

## 3. 产品流程

1. 用户用现有手机应用连接设备。
2. 设备开机后停在实时数据页。滑行时，这一页显示手机发来的实时数据。
3. 三个页面平级：实时数据、本趟报告、AI 教练。短按 DOWN 往后翻，短按 UP 往前翻，首尾相连。
4. 在任何页面长按 OK，都打开教练页。这次按键不开始录音。
5. 在教练页按住 OK 提问，松开 OK 发送。
6. Agent 用语音回答，屏幕上显示简短文字。
7. 等回答或播放回答时，短按 UP 或 DOWN，设备取消这次提问并翻页。
8. 一趟结束后，实时数据页显示这一趟的报告。翻到报告页可以看完整报告。
9. 弯型页在报告页和教练页之间，一次显示上一趟的 8 个弯（D-30）。
10. 手机可以随时让设备弹窗：摔倒提醒、语音播报、问题报告或成就报告（D-31）。按任意键关闭，设备回到弹窗前的页面。
11. 手机判定开始滑行时，设备打开实时数据页（D-32）。正在和教练对话或正在弹窗时，等对话结束或弹窗关闭后再打开。

D-29 取消了滑行模式和休息模式。设备无法检查运动状态，所以语音只在教练页可用。
打开教练页之后，用户还要再长按一次 OK 才会录音。滑行中误碰 OK，最多只会打开教练页。

### 首版不包含的内容

- 指标图表、离线报告缓存和真人对讲。它们在增量 2 之后。弯型视图属于增量 3。
- 自动事故检测或救援调度。摔倒弹窗（D-31）只显示手机发来的提醒，升级处理由手机负责。
- 认证教学、医疗建议或防伤保证。
- 由设备自己测量速度、位置、立刃角或身体姿态。
- 速度排名、速度徽章或任何奖励高速的内容。
- 默认持续监听、唤醒词或常开麦克风。
- 不经手机的无线电对讲。
- 新硬件、量产、支付或公开社交网络。
- 蓝牙加密、配对码或绑定校验。
- 隐私与授权功能。
- 功耗管理，包括休眠模式和低功耗链路参数。

## 7. 体验细节

### 教练页

教练页始终显示接收对象：AI 教练。
页面每次只显示一种状态：就绪、正在听、思考中、回答中或失败。
每种状态都同时使用文字和图标，绝不只靠颜色表达。

长按 OK 500 ms 开始采集。设备立即把每一块声音流式发给手机。
设备不等待网关。手机保存问题，直到网关接受。
用户松开 OK 后，设备停止采集，并告诉手机问题已结束。
单个问题最长 20 秒。

手机把回答逐块流式发回设备。设备每收到一块就播放一块。
屏幕可以显示简短的转写或简短的回答。
识别失败时，屏幕请用户重说。
设备不提供转写编辑，因为三个按键无法编辑文字。

### 翻页与取消

短按 UP 或 DOWN 翻页，三个页面首尾相连。
录音、等回答或播放时，短按 UP 或 DOWN 先取消这次提问，再翻页（D-29）。
取消命令之后 200 ms 内停止播放，100 ms 内停止采集。
长按 UP 和长按 DOWN 没有作用。
短按 OK 留给页面内的操作。目前没有页面使用它。
长按之后不会再触发短按。

### 音频规则

设备绝不同时录音和播放。
播放期间长按 OK，先停止播放，然后才开启麦克风。
链路中断时，设备停止采集并显示故障。
已取消的回答绝不恢复。

### 实时数据页

D-21 让实时数据页显示实时数据。滑行时视线应该在雪道上，所以速度最大，其他每个数字都带名称。

| 区域 | 内容 | 示例 |
| --- | --- | --- |
| 标题 | 页面状态 | LIVE RUN |
| 状态行 | 今日第几趟和滑行状态 | 第 4 趟 · 滑行中 |
| 主数字 | 当前速度 | 38 KM/H |
| 数据面板 | 四格，每格一个名称和一个数值 | 落差 312 m、距离 1.9 km、转弯 24、时间 02:31 |
| 按键提示 | 不变 | 长按 OK 进入休息 |

- 手机判定开始滑行后，先发 RUN_START（D-32），之后每 1 秒发一帧。设备收到一帧就更新一次。
- 收到 RUN_START，状态行立即显示新的一趟，例如"第 5 趟 · 滑行中"。第一帧到达前，每个数字显示"--"。屏幕上已经是这一趟时，收到 RUN_START 数据保留不动。
- 在报告页、弯型页或教练页就绪时收到 RUN_START，设备打开实时数据页。已经在实时数据页时，只刷新数据。
- 和教练对话中，设备先记下开始滑行。对话结束或用户翻页时，设备打开实时数据页。开始滑行不取消任何操作。
- 弹窗中，弹窗不动。弹窗关闭后，设备打开实时数据页，不回弹窗前的页面。
- 状态行显示"滑行中"或"静止"。5 秒没有收到新帧时，显示"数据已过期"，速度显示"--"，面板里的数字保留。
- 还没有任何数据时，状态行显示"等待手机数据"，所有数字显示"--"。
- 一趟结束后，状态行显示"报告生成中"。报告到达后，主数字改为 Heygo IQ，面板改为核心问题和小建议。
- 速度只显示数字，不用颜色、动画或提示音强调高速。
- 手机没有速度时，发送未知值，屏幕显示"--"。

### 每趟报告

D-26 规定：每一趟结束后，手机发送这一趟的报告。D-27 规定报告显示在两个地方：

- **实时数据页。** 一趟结束后，这一页显示这一趟的 Heygo IQ、核心问题和小建议，直到下一趟开始。
- **报告页。** 用上下键翻到报告页，查看完整报告。

| 字段 | 格式 | 示例 |
| --- | --- | --- |
| 第几趟 | 整数 | 第 3 趟 |
| 滑行距离 | 同实时数据 | 1.9 km |
| 转弯次数 | 整数 | 25 弯 |
| Heygo IQ | 0 至 200 的整数 | 82 |
| 核心问题 | 最多 12 个汉字 | 重心偏后 |
| 小建议 | 最多 20 个汉字 | 下一趟把双手放在身体前方 |

- 报告页上长按 OK 打开教练页，与其他页面相同。按键提示写"长按 OK 问教练"。
- D-28：手机发送 SHOW_PAGE 时，设备在实时数据页或教练页空闲时切换到报告页。录音、等回答和播放时忽略这条消息，不打断用户。
- 还没有任何报告时，报告页显示"滑完一趟后显示报告"。
- 报告到达 60 秒后，报告页显示"N MIN AGO"。
- 链路中断后，设备继续显示内存中的最后一份报告。

### 弯型页

D-30 把弯型页加入 D-29 的翻页循环，位于报告页和教练页之间。手机在每趟报告之后发送这一趟的弯数。设备按 8 弯一组向手机请求数据。

- 弯型页一次显示 8 个弯。打开时从左到右画出前 8 个弯，每 40 ms 一个点，小精灵停在线头。
- 之后用强调色标出选中的弯。每次按键后，小精灵沿它走一遍。
- 短按 UP 和 DOWN 换页面，与其他页面相同：UP 到报告页，DOWN 到教练页。长按 OK 进入教练页。
- 在页面内，短按 OK 选中下一弯，长按 UP 选中上一弯，长按 DOWN 跳到下一页（8 个弯）的第 1 弯。页面跟随选中的弯。
- 底部的强调色提示条有两行。第一行是短按："▲报告"、"●下一弯"或"●跳过"、"▼教练"。
- 第二行是当前有效的长按："长按▲上一弯"、"长按▼下一页"，两个都有效时合并为"长按 ▲上一弯 ▼下一页"。没有有效的长按时，显示"长按●问教练"。
- 线下方的细条显示这一页在整趟中的位置。
- 弯型下方显示"TOE SIDE"或"HEEL SIDE"、弯的序号、速度、立刃角和半径。
- 弯型不是来自实测轨迹时，显示"示意"。
- 还没有收到弯型时，显示"暂无弯型数据"。

### 弹窗

D-31 让手机可以随时在设备上弹窗。弹窗页不在翻页循环里。

| 类型 | 屏幕文字 | 颜色 | 徽章 | phone_sim 示例是否带语音 |
| --- | --- | --- | --- | --- |
| 1，摔倒提醒 | 摔倒提醒、FALL ALERT | 红色 | 仰面摔倒的人，头顶有星星 | 是 |
| 2，语音播报 | 语音播报、BROADCAST | 青柠强调色 | 喇叭和声波 | 是 |
| 3，问题报告 | 问题报告、RUN ISSUE | 橙色 | 带"!"的放大镜 | 否 |
| 4，成就报告 | 成就报告、ACHIEVED | 金色 | 奖杯和闪烁的星星 | 否 |

- 每个徽章 4 帧循环播放。弹窗出现时，徽章落下并弹跳，文字框升起。摔倒提醒的徽章还会抖动。

- 弹窗立即打断，任何状态都一样。录音停止，设备取消这次提问。等回答停止。正在播放的回答停止。
- 弹窗显示标题（最多 12 个汉字）和正文（最多 40 个汉字）。没有标题时，设备按类型显示默认标题。
- 弹窗带语音时，设备先播语音，再倒计时 10 秒。不带语音时，立即开始倒计时。
- 语音 5 秒内没有开始，就开始倒计时。
- 底部文字显示"等待语音"、"正在播报"或"N 秒后返回"。最下方的提示条显示"按任意键关闭"。
- 任何按键只关闭弹窗，不翻页，也不开始录音。弹窗之前就按下的 OK 长按，松开时不关闭弹窗。
- 倒计时结束或按键后，设备回到弹窗前的页面：实时数据页、报告页或弯型页。从教练页弹出时，回到教练页的就绪状态。
- 新弹窗替换旧弹窗。设备保留第一个弹窗之前的页面。
- 弹窗中手机开始滑行，或者弹窗打断的对话中手机已经开始滑行，弹窗关闭后都回到实时数据页（D-32）。
- 摔倒弹窗也在 10 秒后自动关闭，不需要用户操作。手机必须自己启动升级处理，例如通知紧急联系人。设备只负责显示。

### 数据字段

D-23 由设备团队定义字段。手机应用团队负责计算和发送。每个字段的格式见 07 号文档第 6 节。

| 字段 | 单位与格式 | 实时数据 | 每趟报告 |
| --- | --- | --- | --- |
| 速度 | km/h，整数 | 有 | 无 |
| 落差 | m，整数 | 有 | 无 |
| 滑行距离 | 不足 1,000 m 显示 m，否则显示 km，一位小数 | 有 | 有 |
| 转弯数 | 整数 | 有 | 有 |
| 滑行时间 | 分:秒。满 1 小时显示时:分 | 有 | 无 |
| Heygo IQ | 0 至 200 的整数 | 无 | 有 |
| 核心问题 | 最多 12 个汉字 | 无 | 有 |
| 小建议 | 最多 20 个汉字 | 无 | 有 |

## 8. 成功指标

这些数字是测试目标，不是实测结果。

| 结果 | 目标 |
| --- | --- |
| 连接 | 10 次中至少 9 次在 180 秒内完成。 |
| 提问与停止 | 5 人中至少 4 人戴手套、无人帮助就能提问并停止回答。 |
| 听到回答 | 从松键到第一句可听回答，第 95 百分位不超过 5 秒。 |
| 及时停止 | 松键后 100 ms 内停止采集。取消命令后 200 ms 内停止播放。 |
| 看懂实时数据 | 5 人中至少 4 人在 2 秒内读对速度。 |
| 数据可信 | 缺失的数据从不显示为 0。 |

## 9. 硬件与试用限制

原型使用现有 AI Passport 开发板和可用手机。
已有资料不能证明防水、低温运行、抗风噪或户外可读性。
室内成功不能作为雪场使用能力的证明。
速度和落差的精度取决于手机，设备不做校验。
量产、认证、包装和售后都不在本概念范围内。
