## 1. 产品目标

滑雪者滑行时在设备上看实时数据，休息时用语音向 AI 教练提问并听到回答。
手机留在口袋里，手套不用摘。

两个增量逐步达成这个目标：

- **增量 1，教练语音链路。** P0 故事 US-01、US-06、US-07、US-08、US-15、US-17、US-20。
- **增量 2，实时数据与报告。** P1 故事 US-02、US-21、US-23、US-24、US-25、US-03。D-22 让它与增量 1 的设备验收并行开发。

## 5. P0 故事

### US-01：设备连接

作为滑雪者，我希望手机能找到并连上我的设备，这样设备可以通过手机连网。

- 验收：设备启动后广播名字。手机应用搜到后直接连接。
- 验收：设备同一时间只接受一部手机。
- 验收：按 D-12，链路不加密、不用配对码、不做绑定校验。
- 依赖：手机应用接受 07 号文档（Q-13）。
- 风险：附近任何蓝牙客户端都能连接。首版接受这项风险。
- 验证：TC-01。

### US-06：语音采集

作为滑雪者，我希望按住一个键就能提问，这样 Agent 能听到我的第一个字。

- 验收：在教练页长按 OK 500 ms 后，麦克风开启。屏幕显示麦克风正在工作。
- 验收：设备立即把每一块 20 ms 的声音流式发给手机，不等待网关。
- 验收：松键后 100 ms 内停止采集。设备告诉手机问题已结束。单个问题最长 20 秒。
- 验收：短按 UP 或 DOWN 取消本次提问并翻页。此后 100 ms 内停止采集。设备告诉手机丢弃这段声音。
- 验收：手机报告识别失败时，屏幕显示简短的重说提示。
- 依赖：US-17，以及能接收流式声音的手机应用。
- 验证：TC-06。

### US-07：语音播放

作为滑雪者，我希望听到回答，并能立即停止，这样我能控制设备。

- 验收：设备每收到一块就播放一块，并显示正在播放。
- 验收：短按 UP 或 DOWN 后，200 ms 内停止播放，然后翻页。设备告诉手机。
- 验收：已取消的回答绝不恢复，迟到的块或重连之后也一样。
- 依赖：US-17，以及能提供合成语音的手机应用。
- 验证：TC-07。

### US-08：按键 Agent 交流

作为滑雪者，我希望向 AI 教练询问我的滑雪情况，这样休息时能得到一条有用的回答。

- 验收：手机把当前滑雪会话附在问题上。
- 验收：回答会标明缺少依据的结论。
- 验收：迟到的回答绝不覆盖更新的提问。
- 依赖：US-06、US-07 和 HeygoAI 的教练能力。
- 验证：TC-08。

### US-15：手套操作与中文显示

作为滑雪者，我希望戴着手套也能操作，并能读懂每一条中文状态。

- 验收：每项核心任务都只需长按一个按键，不需要触摸。
- 验收：每条中文状态文案都完整显示，不缺字、不裁切。
- 验证：TC-15。

### US-17：页面导航

作为滑雪者，我希望用上下键在三个页面之间切换，并且任何时候长按 OK 都能找到教练，这样滑行时绝不会误触语音。

- 验收：设备开机后停在实时数据页。三个页面按实时数据、报告、教练的顺序循环，短按 DOWN 往后，短按 UP 往前。
- 验收：在实时数据页或报告页长按 OK，打开教练页。这次按键绝不启动采集。
- 验收：音频进行时翻页，先停止所有音频（D-29）。
- 验证：TC-17。

### US-20：故障恢复

作为滑雪者，我希望链路出问题时看到明确的提示，这样我知道该怎么做。

- 验收：链路中断时停止音频，并显示链路状态。
- 验收：手机 15 秒没有消息时，显示明确提示。
- 验收：重连不产生重复提问，也不播放过期回答。
- 验证：TC-20。

## 6. 增量 2 故事

增量 2 的数据全部由手机计算。设备只接收、保存最后一包并显示。
字段和包格式见[蓝牙协议草案](07-ble-protocol-draft.zh_CN.md)第 6 节。

### US-02：数据同步

作为滑雪者，我希望设备上的数字和手机算出的一致，这样我能相信它。

- 验收：设备收到 LIVE_STATS 后，显示的总是最新一包。
- 验收：手机发来未知值的字段显示"--"，绝不显示 0。
- 验收：载荷长度不足时，设备回复错误码 2，并继续显示旧包。
- 验收：滑行中 5 秒没有新包时，速度显示"--"，并标明数据过期。报告到达 60 秒后，报告页显示收到时间。
- 依赖：手机应用支持协议 0.2，并接受 LIVE_STATS 和 RUN_REPORT 的字段（Q-16）。
- 验证：TC-02。

### US-21：实时数据页实时数据

作为滑雪者，我希望滑行时扫一眼就知道速度和这一趟滑了多少，这样我不用拿出手机。

- 验收：滑行中，实时数据页显示速度、落差、滑行距离、转弯数、滑行时间和今日第几趟。手机每 1 秒发一帧。
- 验收：速度是页面上最大的数字。
- 验收：一趟结束后，实时数据页显示这一趟的 Heygo IQ、核心问题和小建议，直到下一趟开始（D-27）。
- 验收：还没有数据时，页面显示"等待手机数据"。
- 验收：速度不用颜色、动画或声音强调高速。
- 依赖：US-02。
- 验证：TC-21。

### US-23：开始滑行时打开实时数据页

作为滑雪者，我希望一开始滑行就看到实时数据页，这样我不用在雪道上戴着手套按键。

- 验收：手机判定开始滑行时，发送 RUN_START，带趟数（D-32）。
- 验收：在报告页、弯型页或教练页就绪时，设备立即打开实时数据页。已经在实时数据页时，只刷新数据。
- 验收：第一帧 LIVE_STATS 到达前，页面显示"第 N 趟 · 滑行中"，每个数值显示"--"。屏幕上已经是这一趟时，收到 RUN_START 数据不变。
- 验收：和教练对话中，对话继续。对话结束，或用户短按 UP 或 DOWN 离开时，设备打开实时数据页。
- 验收：弹窗中，弹窗不动。弹窗关闭后，设备打开实时数据页，不回弹窗前的页面。
- 验收：对话中已记下开始滑行，这时弹窗打断对话，弹窗关闭后也回到实时数据页。
- 验收：趟数为 0 或 0xFF 时回复错误码 7，页面和数据都不变。
- 依赖：US-21 和 US-22。
- 验证：TC-23。

### US-24：侧边条

作为滑雪者，我想看到自己在哪一页，以及下一次按键会去哪一页。这样我不用为了找页面而按键。

- 验收：屏幕右边的侧边条用四个格子表示四个页面，顺序与短按 DOWN 一致（D-33）。
- 验收：当前页面的格子是荧光绿滑块。短按 UP、DOWN 会去的格子显示浅灰。侧边条不显示箭头。
- 验收：目标来自流程图。在实时数据页，教练格显示浅灰。在教练页，实时数据格显示浅灰。
- 验收：每次翻页，滑块在 200 毫秒内滑到新格子。绕回时，从一端滑出，再从另一端滑入。
- 验收：录音、等回答和播放时，侧边条保留，目标不变。
- 验收：弹窗页不显示侧边条。弹窗关闭后，侧边条显示保存的页面。
- 验收：侧边条不遮挡文字、方框和按键提示。
- 依赖：US-17 和 US-05。
- 验证：TC-24。

### US-25：每个页面显示连接状态

作为滑雪者，我想在每个页面上看到与手机的连接。这样数据和教练一停，我立即知道。

- 验收：页面循环中的四个页面和弹窗页，在相同位置显示连接圆点和连接文字（D-34）。
- 验收：文字为"已连接"配荧光绿圆点，"未连接"配红色圆点，"无语音"配红色圆点。
- 验收：断开或重连时，当前页面的状态栏立即变化，页面不变。
- 验收：打开新页面时，显示当前的连接状态。
- 验收：状态文字不折行。
- 依赖：US-20。
- 验证：TC-25。

### US-03：每趟报告

作为滑雪者，我希望每滑完一趟就看到这一趟的问题和一条建议，这样下一趟我知道怎么改。

- 验收：从实时数据页短按 DOWN，或从教练页短按 UP，打开报告页（D-29）。
- 验收：报告页显示最后一趟的滑行距离、转弯次数、Heygo IQ、核心问题和小建议。
- 验收：核心问题最多 12 个汉字，小建议最多 20 个汉字，都完整显示，不裁切。
- 验收：还没有任何报告时，报告页显示"滑完一趟后显示报告"。
- 验收：链路中断后，报告页继续显示最后一份报告，并显示收到时间。
- 验收：报告页上长按 OK 打开教练页，与其他页面相同。
- 验收：手机发送 SHOW_PAGE 时，设备在实时数据页或教练页空闲时打开报告页。录音、等回答和播放时不切换（D-28）。
- 依赖：US-02、US-17。
- 验证：TC-03。

### US-05：弯型

作为滑雪者，我希望看到上一趟的线路和其中每个弯，这样我能把报告里的建议对应到具体的弯。

- 验收：弯型页在翻页循环中位于报告页和教练页之间。短按 UP 和 DOWN 换页面，与其他页面相同。
- 验收：弯型页一次显示 8 个弯，并跟随选中的弯。打开时逐点画出第一页，小精灵停在线头。
- 验收：在页面内，长按 UP 选中上一弯，长按 DOWN 跳到下一页（8 个弯）。
- 验收：提示条第一行显示短按，第二行显示当前有效的长按。
- 验收：255 个弯的一趟能正常显示。设备最多保存 3 组，其余的向手机请求。
- 验收：弯型页显示最后一个 RUN_REPORT 的那一趟。这一趟的 TURN_SHAPE 到达前显示"加载中"，没有弯型数据时显示"暂无弯型数据"。
- 验收：短按 OK 切到下一弯。最后一弯之后回到第一弯。
- 验收：每个弯显示边刃、速度、立刃角和半径。未知值显示"--"，绝不显示 0。
- 验收：来源为 1 的弯型显示"示意"。还没有收到弯型时，弯型页显示"暂无弯型数据"。
- 验收：在弯型页长按 OK 进入教练页，不会启动采集。
- 依赖：US-03。实测轨迹依赖 Q-02。
- 验证：TC-05。

### US-22：手机弹窗

作为滑雪者，我希望手机能把重要消息立即弹到设备上。这样遇到摔倒提醒、语音消息、问题或成就时，我不用掏手机。

- 验收：在任何页面、教练页的任何状态下，弹窗都立即显示。录音停止，设备取消这次提问。等回答停止。正在播放的回答停止。
- 验收：四种类型各有自己的名称和颜色。摔倒提醒用红色。
- 验收：带语音的弹窗先播语音，再倒计时 10 秒。不带语音的弹窗立即倒计时。语音 5 秒内没有开始，就开始倒计时。
- 验收：任意键关闭弹窗，不翻页，也不录音。弹窗之前就按下的 OK 长按，松开时不关闭弹窗。
- 验收：倒计时结束或按键后，设备发送 POPUP_END，原因 0 或 1，然后显示弹窗前的页面。从教练页弹出时，回到就绪状态。
- 验收：新弹窗替换旧弹窗。设备为旧弹窗发送 POPUP_END，原因 2，保存的页面不变。
- 验收：字段错误的 POPUP 得到错误码 7、4 或 2，不显示。
- 验收：弹窗期间，CONTEXT 和 DEVICE_STATUS 发送 mode 0、page 6。
- 依赖：US-17、US-20。摔倒提醒的升级处理由手机负责。
- 验证：TC-22。

## 9. 完成定义

增量 1 和增量 2 的每个选定切片，都要满足以下适用检查：

- 用户在实体 AI Passport 上完成操作。
- 切片需要时，路径使用真实的手机应用。
- 主机测试、仓库检查和固件构建全部通过。
- 设备测试在记录的条件下通过。
- 中文显示、按键动作、模式切换和取消行为通过各自的测试。
- 时延测量满足切片的限制。
- 中英文文档描述相同的行为。
- 团队记录每一项剩余缺口。

分别报告构建、主机测试、设备测试和未验证项。
模拟器或桩程序不能满足设备测试或真实服务测试。
