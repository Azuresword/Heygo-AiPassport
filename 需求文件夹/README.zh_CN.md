## 核心体验

滑雪者在休息时查看报告。
滑雪者选择一个指标或一个弯。
滑雪者通过按键向 Agent 提问。
Agent 通过语音回答。
随后，滑雪者可以切换到独立的队伍模式，与真人教练或同伴对讲。

报告、语音输入、语音输出、Agent 交互、真人对讲、图表和弯型可视化共同构成拟定 MVP。
练习目标、技能任务、练习记录、历史对比和分享属于后续候选功能。

## 术语

| 术语 | 在本项目中的含义 |
| --- | --- |
| Agent | 使用当前报告上下文回答问题的 AI 服务。 |
| ASR | 自动语音识别，将语音转换成文字。 |
| TTS | 语音合成，将文字转换成语音。 |
| PTT | 按键对讲。用户按住按键申请发言权限。该权限允许用户短时发言。 |
| 弯 | 一段具有明确时间、方向和数据来源的滑雪动作。 |
| 示意图 | 用于说明概念的曲线，不是实测滑雪轨迹。 |
| BSP | 板级支持包，提供公开的硬件接口。 |
| MVP | 由 P0 需求定义的最小完整产品范围。 |
| Sprint | 固定时长的 Scrum 迭代，产出可用的产品增量。 |
| Definition of Done | 产品增量必须达到的质量标准，也称完成定义。 |
| 发言租约 | 允许某位参与者在房间内短时发言的权限。 |
| 幂等请求 | 重复执行时，不会重复产生已完成效果的请求。 |
| API | 应用程序接口，规定软件组件如何交换请求与数据。 |
| ADC | 模数转换器，将电压转换成数字值。 |
| PCM | 脉冲编码调制，用数字采样值表示声音。 |
| RAM | 软件运行时使用的内存。 |
| PSRAM | 伪静态 RAM，一种额外的运行内存。 |
| Flash | 断电后仍可保留固件和数据的存储器。 |
| IMU | 惯性测量单元，用于测量加速度和旋转。 |
| GNSS | 全球卫星导航系统。接收器利用卫星信号估计位置。 |
| BLE | 低功耗蓝牙，一种无线通信技术。 |
| TLS | 传输层安全协议，用于保护网络连接中的数据。 |
| UX | 用户体验，描述用户如何与产品交互。 |
| 数据来源及处理历史 | 对应英文 data provenance，记录数据来自哪里、经过哪些处理。 |
| IMA ADPCM | 一种简单的音频压缩格式，每个采样用 4 bit 存储。 |
| 延后 | 需求仍保留在记录中，但移出首版范围。 |
| GATT | 蓝牙中关于服务和特征的规则集。 |
| ATT MTU | 双方都接受的最大蓝牙属性包长度。 |

人工复核术语。
启用全部检查规则。
