## 首版做什么

两个增量组成首版：

- **增量 1，教练语音链路。** 滑雪者停下来休息，按住 OK 向 AI 教练提问，并听到回答。
- **增量 2，实时数据与报告。** 滑行中，滑行页显示速度、落差、滑行距离、转弯数和滑行时间。每一趟结束后，设备显示这一趟的报告：滑行距离、转弯次数、Heygo IQ、核心问题和小建议。

手机留在口袋里，手套不用摘。所有数据都由手机计算，设备只负责显示。

D-17、D-18 和 D-22 规定了优先级：

- **P0，增量 1：** 设备连接、语音提问、语音回答和 Agent 交流。P0 还包括模式、手套操作与中文显示和故障恢复。
- **P1，增量 2：** 数据同步、滑行页实时数据和报告页。
- **P1，增量 2 之后：** 指标图表、离线报告缓存和真人对讲。
- **P2，后续候选：** 练习目标、技能任务、复盘日志、会话对比和报告分享。
- **延后：** 弯型可视化、隐私与授权，以及功耗管理。

## 术语

| 术语 | 在本项目中的含义 |
| --- | --- |
| Agent | 回答问题的 AI 服务。 |
| ASR | 自动语音识别，把语音转成文字。 |
| TTS | 语音合成，把文字转成语音。 |
| PTT | 按键对讲。用户按住按键与其他人说话。 |
| BSP | 板级支持包，提供公开的硬件接口。 |
| MVP | 最小完整产品，由 P0 需求定义。 |
| P0、P1、P2 | 优先级。P0 是首版，P1 是下一个增量，P2 是后续候选。 |
| 延后 | 需求保留在记录中，但不在任何已计划的增量里。 |
| Sprint | 固定时长的 Scrum 迭代，产出可用增量。 |
| 完成定义 | 增量必须达到的质量规则，英文为 Definition of Done。 |
| API | 应用程序接口，规定软件组件如何交换数据。 |
| ADC | 模数转换器。 |
| PCM | 脉冲编码调制，用数字采样值表示声音。 |
| IMA ADPCM | 一种简单的音频压缩格式，每个采样用 4 bit 存储。 |
| RAM | 软件运行时使用的内存。 |
| PSRAM | 外接的额外 RAM。这块板没有。 |
| Flash | 断电后仍能保存固件和数据的存储器。 |
| IMU | 惯性测量单元，测量加速度和旋转。 |
| GNSS | 卫星导航系统，接收器用卫星信号估计位置。 |
| BLE | 低功耗蓝牙。 |
| GATT | 蓝牙中关于服务和特征的规则集。 |
| ATT MTU | 双方都接受的最大蓝牙属性包长度。 |

## 文档维护

每份英文文档都要与对应中文文档保持一致。
REQ、US、TC 编号保持不变。
范围变化时，同步更新待办列表和决策记录。

每次更新都使用已安装的 `asd-ste100` 技能。
对英文文档运行结构检查。
人工检查术语、原意和中文文本。

```bash
STE_SKILL="${STE_SKILL:-$HOME/.claude/skills/asd-ste100}"
python3 "${STE_SKILL}/scripts/ste-lint.py" \
  README.md 01-product-requirements.md 02-architecture.md \
  03-scrum-backlog.md 04-validation-and-decisions.md \
  05-decision-amendments.md 06-sprint-0-plan.md \
  07-ble-protocol-draft.md 08-sprint-roadmap.md
```

在本文件夹内运行该命令。技能装在别处时，设置 `STE_SKILL` 环境变量。
自动工具不能证明中文符合标准，也不能证明用词符合 STE 官方词典。
