## 2. 系统边界

```mermaid
flowchart LR
    S[手机或经过验证的外部传感器] --> H[HeygoAI 服务]
    U[手机伴侣应用] -->|配对、账号、授权、房间| G[拟建网关和适配器]
    H <-->|仅使用已验证契约| G
    P[AI Passport] <-->|TLS 控制、报告、音频| W[手机 Wi-Fi 热点]
    W <-->|互联网连接| G
    G <-->|房间音频和发言许可| R[已授权队员]
    P -.->|备选 BLE 控制或音频桥接| U
    U -.->|备选手机转发| G
```

实线表示首个传输候选方案，不表示服务已经存在。
虚线表示 BLE 备选方案。
热点提供网络接入。手机应用不会自动收到热点流量。

先验证手机 Wi-Fi 热点方案。Passport 主动建立到网关的 TLS 连接。
硬件探索任务使用 2.4 GHz 热点。
该方案减少对手机应用持续转发能力的依赖。
该方案仍依赖以下条件：

- 稳定的热点。
- 互联网接入。
- 配网。
- TLS 所需的内存。
- 电池使用情况。
- 服务端支持。

网关适配 HeygoAI 契约，并控制设备会话。
网关也可以承载队伍房间服务。
只有已验证的 HeygoAI 服务覆盖全部契约和安全控制时，才可以取消独立网关。

BLE 方案由手机应用转发数据。
选择该方案前，需要验证手机权限、音频路由、后台限制和重连行为。
本地对讲代码使 BLE 成为可复用的候选方案，但不能替代这些验证。
一次音频交流期间，不自动切换传输方式。

队伍 PTT 指已授权成员之间的网络语音对讲。
队伍 PTT 需要以下条件：

- 可用的传输链路。
- 可达的房间服务。
- 有效的房间成员身份。

它不是离线无线电对讲机。

### 职责分工

| 组件 | 负责 | 不作出的承诺 |
|---|---|---|
| HeygoAI | 契约验证后的账号、滑雪分析、报告和教练能力 | 未公开 API 或可获得的原始传感器数据 |
| 手机伴侣应用 | 账号授权、设备绑定、热点引导、房间选择和可选传感器采集 | 保证后台执行或自动控制热点 |
| 网关和适配器 | 契约转换、有限权限令牌、设备会话路由、房间权限、过期控制和遥测 | 在缺少有效来源时产生新的滑雪测量值 |
| Passport 应用 | 新界面、按键状态、有界缓存、音频所有权、报告绘制和连接状态 | 本地语音识别、本地大模型或已验证的运动感知 |
| Passport BSP | 屏幕、按键、音频格式、音量、总线和其他板级操作 | 产品页面或教练逻辑 |
| 外部数据源 | 带时间戳的样本和声明的测量质量 | 在缺少来源身份和验证时直接获得信任 |

HeygoAI 专用字段保留在适配器内部。
Passport 仅接收和使用标准化消息。
接入真实账号前，先用合成样例测试适配器。

## 3. 模式、按键和页面布局

### 明确的模式

用户手动选择滑行模式或休息模式。
试用版本仅在休息模式开放报告浏览和语音交互。
滑行模式仅显示简要状态，不提供详细图表和语音交互。
设备无法验证用户是否停止移动。

休息模式提供报告、教练和队伍页面。
教练页面将语音发送给 AI Agent。
队伍页面将语音发送给当前房间中的人。
开始录音前和交流期间，持续显示接收对象。
同时使用文字和图标。不仅依靠颜色表达状态。

| 输入 | 拟定行为 |
|---|---|
| 短按 UP 或 DOWN | 移动焦点、翻页或选择报告。 |
| 短按 OK | 确认当前项目。 |
| 在“休息 → 教练”中长按 OK 至少 500 ms | 申请麦克风所有权。开始一次新的 Agent 交流。 |
| 在“休息 → 队伍”中长按 OK 至少 500 ms | 申请独占发言权限。获得发言权限前不录音。 |
| 录音后松开 OK | 停止录音。如有最后一帧，发送这帧后结束传输。最后一帧的大小必须有上限。 |
| 持续录音达到 20 秒 | 停止录音。显示时长上限。 |
| 长按 UP 至少 500 ms | 取消当前交流，或返回上一页。 |
| 在其他页面长按 OK | 不录音。 |

这些时间值是拟定验收值。
长按 OK 后松开按键，不得再次触发短按 OK。
长按 UP 不得再次触发短按 UP。
UP 长按达到 500 ms 时，应用识别取消操作。

200 ms 播放停止预算从达到该阈值时开始计算。
从按下 UP 到播放停止的总目标时间不超过 700 ms。
识别取消操作后，录音必须在 100 ms 内停止。
正常松开 OK 时，100 ms 录音停止预算从松键时开始计算。

按键回调只发送事件，然后立即返回。
任务负责网络、存储和音频操作。

### 拟定的 240 × 320 报告页面

页面使用全新的应用设计，不复用演示菜单或其视觉框架。
坐标单位为屏幕像素，左上角为原点。
当前显示实现包含半径为 30 像素的圆角遮罩。
关键文字必须避开遮罩区域。

| 区域 | 范围 | 内容 |
|---|---|---|
| 状态栏 | `x=32..207, y=0..35` | 休息模式、连接状态和电量状态 |
| 报告标识 | `x=12..227, y=36..67` | 滑雪会话日期、报告标题和缓存标识 |
| 指标行 | `x=12..227, y=68..103` | 两至三个可用指标及单位 |
| 主图区域 | `x=12..227, y=104..247` | 一张图表或一个弯型视图 |
| 上下文 | `x=12..227, y=248..283` | 当前弯、来源质量或数据缺失提示 |
| 按键提示 | `x=32..207, y=284..319` | UP/DOWN 操作和短按 OK 操作 |

滑雪会话摘要、趋势图和单弯详情各用一个页面。
不把所有指标放在同一页。
比较两个弯时使用相同的显示比例。
如果比例变化，显示变化提示。

教练页面显示 Agent 接收对象，以及录音、等待、播放或失败状态。
队伍页面显示房间、当前发言者、发言权限和麦克风状态。
录音期间始终显示麦克风工作标识。
队伍页面断网时禁用录音。

检查全部中文界面文字的字形覆盖。
为每个控件选择预期的中文字库。
UTF-8 输入和编译成功不能证明显示正确。
需要验证戴手套操作和户外文字可读性。

## 4. 数据来源与展示语义

每份报告包含来源、契约版本、报告修订号、采集时间段和生成时间。
每个指标包含单位和质量状态。
未知值使用 `null`。不能将未知值替换成零。
不支持的字段显示为不可用。

| 数据 | 允许的来源 | 展示要求 |
|---|---|---|
| 滑雪会话摘要 | 已验证的 HeygoAI 报告契约 | 显示报告日期和缓存状态。 |
| 速度、距离或海拔 | 具名的手机或外部传感器来源 | 显示单位和缺失区间。 |
| 教练文字 | 经适配器返回的 HeygoAI 响应 | 标明这是 AI 建议。 |
| 转弯方向或阶段 | 有文档的 HeygoAI 算法或已验证来源 | 保留算法版本和置信度含义。 |
| 转弯轨迹 | 带明确坐标系的有效位置样本 | 标明实测或估算。 |
| 弯型示意 | 合成点或形状模板 | 显示“示意图”。不显示米制单位。 |
| 演示内容 | 合成样例 | 在每个相关页面显示“演示数据”。 |

系统不得虚构滑雪评分、立刃角、转弯半径或姿态测量值。
新增派生指标必须提供公式、输入、限制和测试。
除非提供方明确说明，否则置信度不等于概率。

### 时间、缺口和图表

传输和存储使用 UTC 时间戳。
手机提供用户的显示时区。
来源时间戳与接收时间戳分别保留。
数据源缺少统一时钟时，记录时钟不确定性。

图表必须标明坐标轴、单位和时间范围。
不跨越未知区间连接折线。
图表降采样必须保留重要极值和数据缺口。
选中样本时仍可查看精确值。
缓存报告显示生成时间和距今时长。
如果时钟不能确定距今时长，则显示时长未知。

### 转弯坐标和方向

只有来源明确坡面坐标系时，实测弯型才使用局部坡面坐标。
原点为当前弯的第一个有效样本。
`y` 轴正方向沿参考下坡方向。
滑雪者面向参考下坡方向时，`x` 轴正方向朝右。
距离单位为米。

航向角定义为 `atan2(dx, dy)`，单位为度。
从参考下坡方向顺时针旋转，航向角为正。
展开后的航向角变化为正，表示右转。
展开后的航向角变化为负，表示左转。
使用滑雪者行进方向的变化来判断转弯方向。
不能根据曲线位于图中左侧或右侧来判断转弯方向。

只有提供方的方向定义符合本契约时，适配器才保留原始方向标签。
否则，适配器将方向标为未知，或执行经过评审的转换。
仅凭图形不能证明刻滑、立刃角或身体姿态。

示意图使用 0 至 1 的无量纲 `u`、`v` 坐标。
示意图不得暗示实测距离、半径或位置。
缺少坐标系时，不展示实测轨迹。
界面仍可以显示带标签的示意图或已有转弯指标。

每个弯包含开始时间、结束时间、方向、来源和质量状态。
实测点包含 `x_m`、`y_m` 和 `t_ms`。
示意点包含 `u`、`v` 和 `t_ms`。
`t_ms` 表示从当前弯开始时刻经过的毫秒数。
来源缺少时序时使用 `null`。
同一片段内的已知点时间必须递增。

拒绝相互冲突的时间顺序。不得虚构样本时间。
来源缺少时序时，显示静态形状或明确标注的示意步骤。
缺少样本时序时，不宣称按真实时间回放。

缺失区间将轨迹拆分为多个片段。
传感器中断期间不插值补线。
标记裁剪、稀疏采样和不确定方向。

## 5. 拟定的标准化契约

以下名称属于设计方案，不是已验证的 HeygoAI 接口。
探索任务完成后，适配器再映射实际契约。

### 消息封装

| 字段 | 含义 |
|---|---|
| `schema_version` | 契约主版本和次版本，初始为 `1.0` |
| `type` | 报告、控制、Agent 事件、音频帧或房间事件 |
| `message_id` | 用于去重的唯一消息标识 |
| `session_id` | 已授权设备会话 |
| `epoch` | 每次重连后产生的新连接代次 |
| `exchange_id` | 适用时填写 Agent 交流标识 |
| `room_id` | 适用时填写已授权的队伍房间 |
| `lease_id` | 适用时填写当前发言权限标识 |
| `sequence` | 当前流内单调递增的序号 |
| `created_at` / `expires_at` | UTC 有效时间范围 |
| `payload` | 与声明类型一致的有界内容 |

接收方先验证设备会话身份，再接收内容。
消息中的房间或账号字段不能替代服务端授权。
拒绝过期内容。拒绝来自旧设备会话或旧连接代次的内容。
序号缺口产生可见的质量状态或音频丢失事件。

次版本可以增加可选字段。
字段含义或必填字段变化时，升级主版本。
传输首份报告或首帧音频前，协商支持的版本。
忽略未知的可选字段。拒绝不支持的主版本。
在契约中记录枚举扩展规则和必填字段。

`schema_version` 表示契约版本。
`report_revision` 表示报告修订号。
提供方或适配器为同一 `report_id` 分配递增修订号。
拟定的 `generated_at` 字段记录该报告修订版本的生成时间。
该字段与 HeygoAI 数据的映射仍待验证。

每个报告修订版本只应用一次。忽略更早的版本。

如果报告标识和修订号相同，但内容不同，则拒绝该内容。
相同的重复消息不得重置当前页面或音频上下文。

Agent 上下文包含选中的 `report_id`、`report_revision` 和可选的 `selected_turn_id`。
`selected_turn_id` 标识一个滑雪转弯。
`exchange_id` 标识一次 Agent 交流。
同一次 Agent 交流期间，上下文保持不变。
新报告不得静默替换正在进行的交流上下文。

### 候选上限

| 项目 | 初始上限 | 超限行为 |
|---|---|---|
| 控制消息 | 1 KiB | 拒绝超限内容。返回明确错误类型。 |
| 单页报告 | 编码后 8 KiB | 请求下一页。不得分配无限大的文档缓冲。 |
| 缓存报告 | 3 份摘要和一个选中的详情页，总计不超过 64 KiB | 删除缓存中最早的已授权内容。 |
| 单弯轨迹 | 当前弯最多 128 个点 | 请求保留缺口的简化片段。 |
| 并发 Agent 交流 | 1 次 | 先取消或完成上一次交流。 |
| 并发队伍发言者 | 每个房间 1 人 | 拒绝冲突的发言请求。 |
| 单次按住录音 | 20 秒 | 停止录音。释放音频所有权。 |

这些上限需要堆内存测量和真实报告样本验证。
不得通过拆分超大消息来形成无限增长的重组缓冲。

## 6. Agent 与队伍音频状态

应用只有一个音频所有者：None、AgentCapture、AgentPlayback、TeamCapture 或 TeamPlayback。
每个所有者仅控制一个音频方向。
模式变化前，应用先取消当前音频所有者。
试用版本不同时录音和播放。

### 教练流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant P as Passport
    participant G as 网关和适配器
    participant H as HeygoAI Agent
    U->>P: 选择休息模式和教练
    U->>P: 长按 OK 达到 500 ms
    P->>P: 分配交流标识和音频所有权
    P->>G: 携带报告上下文开始交流
    G->>H: 发送已授权 Agent 请求
    G-->>P: 接受当前交流
    P->>P: 检查按键仍按住且交流仍有效
    loop 按住期间，最长 20 秒
        P->>G: 携带交流标识和序号的音频帧
        G->>H: 流式传输或适配受支持的输入
    end
    U->>P: 松开 OK
    P->>G: 结束输入
    G->>H: 完成输入
    H-->>G: 文字或语音响应
    G-->>P: 当前交流的响应
    P->>P: 检查会话、连接代次和交流标识
    P-->>U: 显示回答并播放已授权语音
    opt 用户取消或切换模式
        P->>G: 取消交流
        P->>P: 停止录音并清空待播放内容
    end
```

网关接受当前交流前，麦克风保持关闭。
接受响应到达前，显示可见的等待状态。
松键、取消、过期或模式变化后，拒绝迟到的接受响应。
用户按住 OK 时，适配器可以流式发送输入。
如果 HeygoAI 要求完整音频，网关在服务端上限内缓存。
Passport 不得将完整的 20 秒 PCM 音频保存在 RAM 中。

如果没有语音输出能力，需要验证额外语音服务。
仅文字模式只用于诊断，不满足 REQ-07 或 P0 验收。
真实语音输出通过完整链路测试前，MVP 保持阻塞。

用户可以在录音、等待或播放期间取消交流。
取消操作使交流标识失效。取消操作还会清空播放队列。
旧交流的迟到响应不得播放。
重连产生新的连接代次，并取消原来的交流。
仅发送用户允许的报告上下文。

### 队伍 PTT 流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant P as Passport
    participant R as 房间服务
    participant T as 队伍接收者
    U->>P: 选择休息模式和队伍房间
    U->>P: 长按 OK 达到 500 ms
    P->>R: 请求发言许可
    Note over P: 麦克风保持关闭
    alt 当前请求仍有效，用户仍按住按键
        R-->>P: 返回带标识和过期时间的发言许可
        P->>P: 显示麦克风工作状态
        loop 按住期间，最长 20 秒，且许可未过期
            P->>R: 携带会话、连接代次、房间和许可的音频
            R->>T: 当前已授权发言者的音频
        end
        U->>P: 松开 OK
        P->>P: 停止麦克风
        P->>R: 结束发言并释放许可
    else 忙碌、超时、松键或断线
        P->>P: 取消请求，麦克风保持关闭
    end
```

服务端向一名发言者授予有时限的发言权限。
该权限提供独占发言权。它不提供永久房间访问权。
拟定的发言权限在授予后 25 秒内过期。
出现以下任一情况时，立即停止录音：

- 录音达到 20 秒。
- 用户松开 OK。
- 交流取消。
- 发言权限过期。
- 连接中断。

使用单调时钟控制本地截止时间，且不得晚于服务端过期时间。
如果时钟不确定性使本地截止时间不安全，则拒绝发言权限。
房间服务也拒绝过期后的音频。

如果收到发言权限时，用户已经松开 OK：

1. 拒绝该发言权限。
2. 释放该发言权限。

使用请求标识拒绝迟到的发言权限。
重连后需要以下各项：

- 新的房间授权。
- 新的连接代次。
- 新的发言权限。

不得自动恢复中断的传输。
不得缓存队伍语音以便稍后投递。
丢弃迟到音频帧。不得重播旧语音。

队伍播放要求同时满足以下条件：

- 休息模式处于启用状态。
- 队伍页面处于打开状态。
- 音频属于当前房间。
- 音频所有权处于空闲状态。

队伍语音不得混入 Agent 输入或回答。
切换房间或账号前先停止录音。
即使松键事件丢失，录音时限和发言权限过期机制仍必须生效。

## 7. 设备边界与资源

使用现有 BSP 执行硬件操作。
页面、协议状态、会话和应用任务属于应用层。
LVGL 任务之外的代码访问 LVGL 对象前，必须持有 `bsp_lvgl_lock()`。
删除界面前，停止会访问该界面的任务、定时器、回调和事件处理器。

通过 BSP API 修改音频编解码器、时钟或采样格式。
不得在按键处理器或应用页面中直接修改编解码器寄存器。
改变现有硬件配置前，先测量音频行为。

### 初始内存预算

16 kHz、单声道、16 bit PCM 每秒使用 32,000 字节。
20 秒音频需要 640,000 字节，且尚未包含协议开销。
设备没有 PSRAM，不应在 RAM 中保存完整音频。

| 分配项 | 初始设计 | 证据或限制 |
|---|---|---|
| LVGL 绘制缓冲 | 单个 40 行 RGB565 缓冲 | 当前源码使用 19,200 字节。 |
| LVGL 内存池 | 24 KiB | 当前 `sdkconfig.defaults` 配置。 |
| 音频环形缓冲 | 接收 8 KiB，发送 8 KiB | 拟定值。避免同时进行录音和播放。 |
| 控制队列 | 8 项，每项不超过 1 KiB | 拟定值。拒绝超量消息。 |
| 报告解析 | 单页不超过 8 KiB | 拟定值。测量时计入解析器开销。 |
| 弯型坐标 | 最多 128 个点 | 拟定值。片段数和点数都设置固定上限。 |
| TLS、Wi-Fi、任务栈、字库和固件 | 根据选定传输方式测量 | 不宣称剩余内存已经足够。 |

8 KiB 约容纳 256 ms 的候选 PCM 音频。
每个环形缓冲都必须定义溢出策略。
音频溢出时，根据通道契约停止交流或丢弃过期帧。
不得因为网络缓慢而无限扩大队列。

当前源码使用 80 MHz SPI 时钟。
这个值不能证明屏幕帧率或可用网络吞吐量。
旧版指南提到 20 行缓冲。本方案以当前实现为准。

探索任务先使用 PCM，或经过端点验证的编解码格式。
本地 BLE 参考使用 20 ms IMA ADPCM 帧，并要求 ATT MTU 至少为 172。
参考中还包含八帧播放队列和 1,500 ms 请求超时。
这些值仅供参考，尚未成为正式产品限制。

当前音频配置使用六个 DMA 描述符，每个包含 240 帧。
该容量不能证明完整链路的语音延迟。
复用前，需要验证手机实现、编解码约定、身份认证和实测丢包。

### Flash 与存储数据

默认分区保持精简：NVS、PHY 数据和一个 factory 应用分区。
按 8 MB Flash 容量验证全部镜像。
不能假设字库和固件之外仍能容纳两个 OTA 应用槽。
OTA 需要单独的容量决策和恢复测试。

持久化报告缓存需要明确的存储决策。
不得把新增缓存分区当作模板的隐含要求。
限制缓存大小。
明确账号归属、保留期限和数据删除规则。
存储设计必须在断网和重启后保留一份完整且有权限的报告，否则 REQ-13 阻止试用验收。

新缓存快照以原子方式提交。更新失败时保留上一份完整快照。
64 KiB 缓存上限不代表当前分区表已经预留这些空间。
如果仍满足 REQ-13，选定布局可以使用更小的缓存。

## 8. 信任、访问与失败处理

手机负责账号登录和用户授权。
网关保存 HeygoAI 凭据及提供方密钥，Passport 不保存这些秘密。
Passport 仅接收短期令牌，其权限限定到设备、账号绑定和允许的服务。
房间访问还需要独立的房间授权检查。

检查 TLS 证书。不得通过跳过证书检查来解决时钟或连接问题。
配网设计必须建立可信时间和设备绑定关系。
不得通过未认证的 BLE 特征传输账号凭据。
BLE 方案需要经过认可的配对和绑定方法，并提供可见的设备关联步骤。

服务端逐一验证报告、Agent 交流和房间请求的身份。
客户端提供的账号标识不得用于选择其他用户的数据。
房间事件绑定当前账号、房间、设备会话和连接代次。
撤销授权后，服务端停止接受新请求。
设备收到撤销通知或本地访问权限到期后，删除失去授权的缓存内容。

离线设备无法即时收到远程撤销通知。
离线缓存访问需要独立且会过期的授权，以及明确的保留策略。

默认不在处理或投递完成后保留语音。
如果增加录音保存功能，需要独立授权、保留期限和删除控制。
诊断数据必须移除令牌、语音内容和个人滑雪数据。
用户可以解除设备绑定。用户可以删除该设备中已授权的本地数据。

| 故障 | 设备行为 | 服务端行为 |
|---|---|---|
| 网络中断 | 停止录音。显示离线状态和缓存报告时间。 | 使请求和发言权限过期。 |
| Agent 超时 | 结束交流。等待用户重新发起操作。 | 拒绝迟到或已取消的输出。 |
| 队伍房间忙碌 | 麦克风保持关闭。显示当前发言者。 | 维持唯一有效发言者。 |
| 报告无效 | 保留最近一次有效且有权限的页面。标明不可用字段。 | 返回明确错误类型。不得泄露私人数据。 |
| 音频队列溢出 | 按通道规则停止或丢弃过期音频。 | 记录有界丢失。不得重放。 |
| 内存不足 | 在分配失败前停止音频。显示可恢复错误。 | 停止向失效交流推送数据。 |
| 电量未知 | 显示未知电量状态。 | 不推导电量百分比。 |
| 账号或房间变化 | 停止音频。使旧上下文失效。 | 拒绝旧令牌和旧房间权限。 |

离线模式仅支持本地可用且有权限的报告内容和基础界面。
离线模式不代表支持离线 AI 推理、语音识别或队伍 PTT。
